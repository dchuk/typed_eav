2. "IMPROVEMENT PROGRAM 2: invalid-cast persistence" - `validate_value` (`value.rb:391-395`) self-consumes `@cast_was_invalid` by resetting it to `false` after the first error. "IMPROVEMENT PROGRAM 5: field/query Integer casting agreement" - `Field::Integer#cast` (`field/integer.rb:17-28`) rejects fractional input (`bd.frac != 0` -> `[nil, true]`) and strips whitespace, but `QueryBuilder` never calls `field.cast` for comparison operators. Repro: create an `:integer_field`, assert the write-side contract holds (`field.cast("7.5") == [nil, true]`), then assert the query side AGREES - `expect { TypedEAV::QueryBuilder.filter(field, :eq, "7.5") }.to raise_error(ArgumentError)` and the same for `:gt` with `"3.7"`. Assert the desired AGREEMENT, not a particular implementation.
