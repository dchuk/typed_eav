<objective>
Give TypedEAV::Field an optional, free-text display label independent of its slug `name`, with one
canonical reader (`display_name => label.presence || name.humanize`) for all human-facing rendering.
`name` stays the immutable machine key; `label` is purely cosmetic and never participates in
uniqueness, lookup, partitioning, rename detection, or ordering. Fully additive and backwards
compatible: existing rows keep label NULL and render identically to today. Schema portability
round-trips the raw label (regular export) and the resolved display_name (snapshot export), with
legacy payloads (no `label` key) importing as NULL with no version gate.

Tasks are a strict linear chain (migration -> model -> schema portability -> docs) with tests
interleaved per task (TDD red-green). Single plan, single wave; there is no file-level reason to
split. Suite is RSpec (~820+ examples) and must stay green.
</objective>
